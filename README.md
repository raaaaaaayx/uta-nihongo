# 唱歌学日语

用本机的 Apple Music 或网易云音乐播放日语歌，同步显示带假名、中文翻译、语法 / 词汇标注的歌词。

介绍网站：<https://raaaaaaayx.github.io/uta-nihongo/>

## 直接安装 Mac App（推荐）

不需要安装 Node.js，也不需要浏览器。支持 Apple 芯片（M 系列）和 Intel 芯片的 Mac，需要 macOS 13.5 或更新。

**方法一：一行命令（最省事）**　打开「终端」粘贴运行。会自动认出芯片、下载最新版、放进「应用程序」并打开，第一次打开也不会被系统拦：

```bash
curl -fsSL https://raw.githubusercontent.com/raaaaaaayx/uta-nihongo/main/install-app.sh | bash
```

**方法二：自己下载**　到 [Releases](https://github.com/raaaaaaayx/uta-nihongo/releases/latest) 下载对应芯片的压缩包：Apple 芯片选 `uta-nihongo-macOS-arm64.zip`，Intel 芯片选 `uta-nihongo-macOS-x64.zip`（不确定的话：左上角苹果标志 → 关于本机）。解压后把「唱歌学日语」拖进「应用程序」。

这样下载的 App 没有经过苹果公证，第一次打开时 macOS 会拦下来、提示无法验证开发者，放行一次即可：
  - **macOS 15 及更新**：先双击打开一次（会被拦），然后到「系统设置 → 隐私与安全性」，往下找到「唱歌学日语」那一行，点 **仍要打开**，输入密码
  - **macOS 14 及更早**：在「应用程序」里 **右键 → 打开**，再点「打开」
  - 或者在「终端」里运行一次：`xattr -dr com.apple.quarantine /Applications/唱歌学日语.app`

**更新**：每次打开都会检查有没有新版本，有的话顶部会出现提示，点「立即更新」，App 会自己下载、换上新版并重新打开（词汇书和设置都保留）。

支持 Apple Music 和网易云音乐（在「设置 → 更多设置 → 程序 → 播放器」里切换）。

## 从源码安装

需要：Mac、Apple Music 、[Node.js](https://nodejs.org)

打开「终端」输入：

```bash
curl -fsSL https://raw.githubusercontent.com/545DedicatusRL/uta-nihongo/main/install.sh | bash
```

程序会被装到 `~/Applications/唱歌学日语`，桌面会生成「唱歌学日语」图标。第一次启动时系统会问是否允许它控制「音乐」，点 **允许**。

**更新**：再运行一次指令。只更新程序文件，词汇书、设置和缓存（`data/` 文件夹）会保存。每次打开程序都会检查有没有新版本，有的话顶部会出现提示，点「复制更新命令」粘贴到终端运行即可。

安装到其他位置 `UTA_DIR=`，例如 `curl -fsSL …/install.sh | UTA_DIR=~/uta bash`。

使用git：`git clone https://github.com/545DedicatusRL/uta-nihongo.git`，然后双击 `唱歌学日语.command`。

## 启动

装好以后双击桌面上的「唱歌学日语」图标。

或双击程序文件夹里的 `唱歌学日语.command`（或在终端里 `npm start`，然后打开 http://localhost:3939)

第一次运行时，程序会在桌面生成「唱歌学日语」图标，以后双击它即可：第一次启动时，系统可能会询问是否允许它访问「文稿」文件夹、控制 Music，点允许即可。

界面窗口默认使用 Chrome。可在设置中更改

退出：「设置 → 更多设置」最下方点「退出唱歌学日语」，或在程序坞的图标上右键退出。只关掉界面窗口不会退出程序。后台运行的记录在 `data/app.log`。

桌面图标删掉后不会自动重新生成；想重新生成，删除 `data/.shortcut-created` 后再启动一次。

图标固定指向创建它的那份程序。如果电脑上有不止一份（比如旧位置的副本），双击图标时会先停掉正在运行的另一份，再启动自己这一份；「更多设置」里能看到当前运行的版本和程序位置。

第一次启动时 macOS 会问「是否允许控制 Music」，请点 **允许**。之后在 Apple Music 里放歌，或从界面左上角的「资料库」里选歌即可。

## 功能

- **播放**：读取本机 Apple Music 资料库和播放列表，播放 / 暂停 / 拖动进度都由 Apple Music 完成。
- **专辑**：资料库的下拉菜单里选「全部专辑」，按专辑浏览；点进一张专辑按曲序显示，从里面点歌就播这张专辑。
- **仅日文**：按流派、假名和内置的日本歌手名单自动判断。漏掉的歌：取消勾选「仅日文」，把鼠标移到那首歌上点右边的「日」，就把这位歌手标为日文歌手；标过的再点一次取消，也可以在「设置 → 更多设置 → 资料库」里统一管理。
- **播放列表**：在「资料库」里点一首歌，当前筛选出来的列表（「仅日文」、搜索、所选播放列表）就成为播放列表，从这首开始，播完自动接下一首。播放键两侧是「随机播放」和「播放列表」；列表里可以点任意一首跳过去，也可以开「列表循环」。顺序由本程序决定（Apple Music 每次只播一首），所以需要程序保持运行；在 Apple Music 里自己换了列表外的歌，程序就不再接管。播不了的歌会自动跳过。
- **歌词**：播放时自动从网易云音乐、QQ 音乐匹配（英文曲名会先反查日文原名）。有逐字时间轴时按字填充，否则逐行。可在「歌词源」里手动换源或搜索。
- **两种样式**：「滚动」（Apple Music 风格）和「大字」（单句大字 + 翻译），默认按 `F` 切换。
- **假名**：本地词库（kuromoji）自动注音，并用歌词源的罗马音 / QQ 注音纠正实际唱法；顶栏的「修改」模式下点汉字可手动修改（仅这一句 / 本曲 / 所有歌曲）。
- **语法 / 词汇标注**：内置约 100 条语法规则；词汇释义默认中文（有道日汉词典），JLPT 级别和英文释义来自 Jisho。在「设置」里可调样式、数量、级别、释义语言；多义词会优先显示和这一句中文翻译对得上的义项；在顶栏的「修改」模式下点某个标注，可以在这首歌里隐藏它（再点一次恢复），鼠标停在多义词的标注上会展开其他义项的小卡，点一张即换上它（自动选义可在设置里关闭）
- **记词（辞书模式）**：按 `D` 或点「记词」，点击歌词里的词（可连续点选组合，或切换为按字），点「完成」加入词汇书。词汇书可导出 CSV。
- **词汇书的记忆模式**：点词汇书里的「记忆模式」，词条会被打乱，释义、例句和翻译整块模糊；先自己回想，再把鼠标移上去点「展示释义」对答案。再点一次「记忆模式」恢复显示和默认顺序（按添加时间）。旁边的随机图标可以单独打乱 / 还原顺序。
- **快捷键**：空格 播放 / 暂停，←/→ 上一句 / 下一句，`F` 切换样式，`D` 记词，`E` 修改，`[` `]` 调歌词时间。都可以在「设置 → 更多设置 → 快捷键」里改，也可以给上一首 / 下一首、随机播放、资料库等指定按键。
- **时间对齐**：`[` / `]` 微调，或在「对齐」里开启敲击对齐。偏移按歌曲保存。
- **自定义与修改**: 由于歌曲中汉字的读音多样，虽然内置功能会自动修复读音，但有时仍会标注错误读音。对于错误的读音，可以在编辑模式中对假名自行更改。同时，对于有多个注释的词语，有时候会出现标注错误的情况，系统默认自动校正，如遇校正后仍错误的情况，在编辑模式也可以选择其他的注释。修改模式也可以选择注释不做选择。


## 网易云音乐

默认为自动切换，目前网易云的实现方式基于调试窗口，需要由程序开启网易云。网易云与Apple Music同时播放时系统会提示用户选择，避免冲突。

## 更新

运行：

```bash
tools/update-local.sh
```

这会让本机正在用的程序换成这份代码的最新版：正在运行的就是这一份原地重启（界面自动刷新），否则通过桌面图标启动并替换掉另一份；最后核对运行中的版本、位置和桌面图标的指向。

## 数据

所有数据（词汇书、读音修正、偏移、歌词缓存、设置）都在 `data/` 目录里，删除即重置。

## 目录

- `server/` — 本地服务：`music.js`（Apple Music 桥接）、`lyrics.js`（歌词源）、`japanese.js`（分词 / 注音 / 纠错）、`grammar.js`（语法规则）、`annotate.js`（Jisho / Claude）
- `public/` — 界面
